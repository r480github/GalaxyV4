# Galaxy🪐

~Browse the internet with no restrictions

## About Galaxy📑

Galaxy is a minimalistic open source proxy that is capable of evading internet censorship. Galaxy uses Chemical.JS, which is harder to detect and fast. It also contains a vast collection of games that will continuously expand as the site grows. Join [Hydra Network](https://discord.gg/Dvh2veTWU4) for more links!

## Run Galaxy Locally 🚀

##### Install Galaxy
```bash
git clone https://github.com/r480github/GalaxyV4.git
cd GalaxyV4
```


<br>

##### Install dependencies

```bash
npm i  
```

##### Start

```bash
npm start
```
#### NOTE: The dafault port for GalaxyV4 is 3000. You can visit it by typing localhost:3000/ into a web browser. Editing the port inside app.js, will change the port. Please do this if you run into an issue that says your port is closed/busy.
